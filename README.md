# 放置天堂－日出之國

《放置天堂－日出之國》網頁版原始檔與 GitHub Pages 部署設定。

## 遊玩

部署完成後，可直接從本儲存庫的 GitHub Pages 網址開啟遊戲。

## 本機啟動

進入 `放置天堂-鐵匠附魔-v3.9.13-雷光哨衛試作版` 資料夾後執行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

再以瀏覽器開啟 <http://127.0.0.1:4173/>。
